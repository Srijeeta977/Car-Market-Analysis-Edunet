# Car Market Analysis

## Data Analytics Internship Project – Edunet Foundation

### Project Overview

Car Market Analysis is a data analytics project based on historical Car Dekho used-vehicle data.

The project analyzes vehicle characteristics, selling prices, present prices, kilometers driven, fuel type, seller type, transmission, and previous ownership to identify important market trends and pricing patterns.

### Problem Statement

The used-car market contains vehicles with different prices, fuel types, transmission types, usage levels, and ownership histories. Understanding the factors that influence selling prices can help buyers, sellers, dealers, and used-car businesses make better decisions.

### Objectives

- Analyze used-vehicle market trends.
- Identify popular vehicle models.
- Study selling price and present price patterns.
- Analyze vehicle depreciation.
- Examine the relationship between vehicle age, kilometers driven, and selling price.
- Compare cars and two-wheelers.
- Identify potentially exceptional deals.
- Generate data-driven insights for pricing and purchasing decisions.

### Dataset

The dataset contains information about used vehicles, including:

- Car/Vehicle Name
- Manufacturing Year
- Selling Price
- Present Price
- Kilometers Driven
- Fuel Type
- Seller Type
- Transmission
- Previous Owners

The analysis provides insights into:

- Used-vehicle price ranges

# How to Run
1. Download or clone this repository.
2. Open Car_Market_Analysis_Edunet.ipynb in Google Colab or Jupyter Notebook.
3. Make sure Car_Dekho_Data.csv is available in the working directory.
4. Run the notebook cells sequentially.

The project demonstrates how Python-based data analysis and visualization can be used to transform historical automobile data into meaningful insights that support better buying, selling, and pricing decisions.
